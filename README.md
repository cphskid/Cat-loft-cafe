# 暖陽貓閣 Cat Loft Cafe

用 Scratch 3.0 製作的貓咪咖啡廳經營模擬遊戲。

## 目前進度
- MVP 範圍：只做第一階段（Stage 1）
- 設計文件審閱：[docs/暖陽貓閣_GDD審閱.md](docs/暖陽貓閣_GDD審閱.md)

## 已確定的設計決策（2026-10-10）
- 起始資金 ¥100（普通難度）
- 名聲分 3 級
- 沒有 Game Over：缺錢可以借款還債，或用手機 App 賒帳購買
- 2 樓收入場費，價格可調整
- 貓咪可在兩層樓自由走動（廚房除外）
- 早上備料時時鐘暫停
- 角色會自己走動；切換樓層檢視，有事件時顯示提示圖示
- 不使用雲端變數，改用存檔碼存讀檔

## 檔案結構
- `docs/`：設計文件與審閱
- `scratch/`：Scratch 專案檔（.sb3），之後加入
